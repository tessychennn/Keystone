# Keystone

每週把時間分配出去，每天記下實際花掉的，順手把想法留住。

拱心石是拱頂正中那塊楔形石，鎖住左右兩側的砌石；抽掉它整座拱就垮。
這個 app 想當的是一週的那塊石頭。

---

## 開始用

連點兩下 `index.html`。沒有安裝步驟。

想要更像一個 app：在 Chrome 開啟後，網址列右側選「安裝」或「建立捷徑」，
勾「在視窗中開啟」。之後它會有自己的視窗和圖示，不混在瀏覽器分頁裡。

## 兩個分頁

**週曆** — 先在左欄列出工作項目和每週想投入的時數，最上面那條軌會顯示時間怎麼分配出去；
如果項目加總超過總時數，會出現紅色預算線。點一個項目（整列都能點），
在週曆格子上按住往下拖，放開就記下一筆，拖曳長度就是時數（一格 30 分鐘）。
色塊可以拖去別天、點開微調或刪除。項目要改名就雙擊名稱。

左欄下面是**今日待辦**：開工前要記得做的事。打勾整列沉下去，隔天早上全部重新浮起來。
新增時可以選「每天」（例行事項）或「只有明天」（一次性提醒，勾完隔天自動消失）。

**筆記** — 跟週曆完全無關的一份清單，不綁任何一週。標題、分類、內容。
分類點那顆色球進去管理，可以新增、改名、換色、刪除；刪分類不會刪到底下的筆記，
它們會移到「未分類」。

## 資料存在哪

存在**這台電腦的瀏覽器**裡，不會上傳到任何地方。
一年累積下來大約 0.2 MB，不到一張照片的二十分之一。

要注意的事：

- 換瀏覽器、清掉網站資料、或用無痕模式開，資料就不在了。
- **手機和電腦目前不會同步**，各存各的。
- 瀏覽器不讓存資料時，畫面最上面會出現紅字警告——看到就代表這次的紀錄關掉就沒了。

所以：**定期按「匯出備份」**，會下載一份 JSON。換機器或出事時用「讀入備份」還原。

要真正的跨裝置同步，`CLAUDE.md` 裡寫了怎麼接——只需要改 `storage.js` 一個檔案。

> 這個 app 本來叫 Buoy。如果你用過那版，資料會在第一次開啟新版時自動搬過來。

## 用 Claude Code 繼續開發

在這個資料夾開 Claude Code 就可以。`CLAUDE.md` 裡寫了設計系統、資料模型、
已知的坑，以及哪些事不要做（例如不要加建置流程）。

建議先 `git init`，之後每次改動都有得退。

## 檔案

```
index.html    畫面
styles.css    樣式
app.js        邏輯
storage.js    儲存層（要換同步後端就改這裡）
icon.svg      圖示
CLAUDE.md     給 Claude Code 的專案說明
```

純前端，沒有依賴套件，沒有建置步驟。
